Sound samples (FluidR3_GM, converted to per-note MP3 by Benjamin Gleitzman's midi-js-soundfonts)
Source: https://github.com/gleitz/midi-js-soundfonts  (FluidR3_GM)
License of the sound data as stated by that project: Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/us/)
Code of midi-js-soundfonts: MIT (see LICENSE-midi-js-soundfonts.txt)
Only a subset of notes (every 3 semitones) of 7 guitar, 6 bass and 17 keyboard/orchestral instruments is included; the app pitch-shifts between them.

Additional instruments are bundled as one JSON file per instrument in samples/pack/ (base64 MP3 of the same FluidR3_GM notes, every 3 semitones). Same source and license.
